# Provenance

ClonoForge 1.0.0 derives from the qualified ClonoForge implementation. Scientific scope, input contracts, and limitations are described in the [manual](docs/USER_MANUAL.md), [manuscript](docs/ClonoForge-Manuscript.pdf). The manuscript identifies the measured binaries and inputs; benchmark results apply to the stated environment and timed boundary. Source and dependencies are provided under their respective licenses.

Repository: https://github.com/Yoonecorn/ClonoForge

The benchmarked source was historical commit `c20a8a127d2fdccd35b9af7d8c65c6d806d2ada0`, whose Git tree was `f0e2aa6cda0391c2952c1d49d668c7dd237eb2b2`. The public repository begins from a release snapshot and does not contain that historical commit. Its scientific source and locked dependencies match the evaluated source; package metadata adds the repository URL, and CLI help names the canonical manual. Documentation and manuscript availability wording are updated. The benchmarked executable and the release source are distinct artifacts.
